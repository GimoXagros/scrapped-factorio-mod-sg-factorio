# SG Factorio

[sungjin-bae/SG_Factorio](https://github.com/sungjin-bae/SG_Factorio)에서 가져온 Factorio 모드 작업 파일입니다.

실제 모드는 [mods/BSJ_1.1.0](mods/BSJ_1.1.0)에 있습니다. [info.json](mods/BSJ_1.1.0/info.json)은 이름 `BSJ`, 버전 `1.1.0`, 대상 Factorio `0.16`, 의존성 `base`를 선언합니다. 설치할 때는 저장소 전체가 아닌 이 모드 폴더를 사용합니다.

하위 [README](mods/BSJ_1.1.0/README.md)는 You've Got Mail! 기능을 설명하는 원본 문서입니다. 현재 manifest의 `BSJ Test` 이름과 구분해서 읽어 주세요. 라이선스는 [모드 폴더](mods/BSJ_1.1.0/LICENSE)에 보존되어 있습니다.
